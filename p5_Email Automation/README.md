# Email Automation

A Python automation project designed to send emails programmatically using Python.

## Features

- Automates email sending.
- Uses SMTP for email communication.
- Supports sending messages through an email server.
- Reduces repetitive manual email tasks.

## Technologies

- Python
- smtplib
- email
- SSL/TLS

## Project Files

- `Email Automation.py`: Main Python script.

## Requirements

The project uses Python standard libraries:

- smtplib
- email
- ssl

No additional package installation is required.

## How to Run

1. Make sure Python is installed.
2. Configure the email server settings and credentials securely.
3. Run:

```bash
python "Email Automation.py"
```

**Security Note:** Never store email passwords or app passwords directly in the source code. Use environment variables or another secure method to manage credentials.

## Purpose

This project demonstrates email automation and SMTP communication using Python.
