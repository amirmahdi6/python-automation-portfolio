# Large Files Finder

A Python automation script that finds files larger than a specified size.

## Chapter

Chapter 10 - Organizing Files

## What This Project Does

This script searches through folders and identifies files that are larger than 100 MB.

## Files

* `e4_100 mb.py` - Main Python script

## Technologies

* Python
* `os`
* File system traversal
* File size checking

## How to Run

Run the following command:

```bash
python "e4_100 mb.py"
```

The script will search the specified folders and report files that are larger than 100 MB.
