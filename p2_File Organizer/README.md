# File Organizer

A Python automation project that organizes files into separate folders based on their file types.

## Features

- Scans files in a target directory.
- Identifies file extensions.
- Organizes files into categorized folders.
- Automates repetitive file management tasks.

## Technologies

- Python
- OS Module
- File Handling

## Project Files

- `File Organizer.py`: Main Python script.
- `test folder`: Sample directory for testing the project.

## How to Run

1. Make sure Python is installed.
2. Run the script:

```bash
python "File Organizer.py"
```

## Purpose

This project demonstrates file system automation and directory management using Python.
