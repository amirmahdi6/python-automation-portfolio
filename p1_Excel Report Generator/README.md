# Excel Report Generator

A Python automation project that reads sales data from an Excel spreadsheet, processes the data, and generates a sales report.

## Features

- Reads sales data from an Excel file.
- Extracts product quantities and prices.
- Calculates total sales for each product.
- Processes spreadsheet data automatically.

## Technologies

- Python
- OpenPyXL

## Project Files

- `Excel Report Generate.py`: Main Python script.
- `sales.xlsx`: Input Excel spreadsheet.

## Requirements

Install the required library:

```bash
pip install openpyxl
```

## How to Run

1. Make sure Python is installed.
2. Install OpenPyXL.
3. Place `sales.xlsx` in the same directory as the Python script.
4. Run:

```bash
python "Excel Report Generate.py"
```

## Purpose

This project demonstrates basic Excel automation and data processing using Python.
