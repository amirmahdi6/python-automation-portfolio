# Text to Spreadsheet

A Python script that reads data from text files and writes the information into an Excel spreadsheet.

## Chapter

Chapter 13 - Working with Excel Spreadsheets

## What This Project Does

The script reads data from multiple text files and organizes the information into an Excel spreadsheet.

## Files

* `textToSpreadsheet.py` - Main Python script
* `file1.txt` - Example input file
* `file2.txt` - Example input file
* `file3.txt` - Example input file
* `textToSheet.xlsx` - Generated Excel spreadsheet

## Technologies

* Python
* `openpyxl`
* Text file handling
* Excel spreadsheet manipulation
