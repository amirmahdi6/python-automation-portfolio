# Regex Number & Email Extractor

A Python script that extracts phone numbers and email addresses from text using Regular Expressions.

## Project

Regular Expression - Number and Email Extractor

## What This Project Does

The script reads text from the clipboard, searches for phone numbers and email addresses using regular expressions, and copies the extracted results back to the clipboard.

## Files

* `E2_MAIN.py` - Main Python script

## Technologies

* Python
* Regular Expressions (`re`)
* `pyperclip`

## How to Run

First, install the required package:

```bash
pip install pyperclip
```

Then run:

```bash
python E2_MAIN.py
```

Copy some text containing phone numbers or email addresses before running the script.

The extracted results will be displayed in the terminal and copied to the clipboard.
