# ZIP Backup

A Python automation script that creates ZIP backups of files and folders.

## Chapter

Chapter 10 - Organizing Files

## What This Project Does

This script uses Python to create a ZIP archive from a folder and its contents.

## Files

* `e2_zip.py` - Main Python script
* `test_backup/` - Example folder used for creating the backup

## Technologies

* Python
* `os`
* `zipfile`
* File and folder handling

## How to Run

Run the following command:

```bash
python e2_zip.py
```

Make sure the required files and folders are available before running the script.
