# XKCD Downloader

A Python automation script that downloads XKCD comic images automatically.

## What does it do?

The script:

- Connects to XKCD website
- Downloads comic pages
- Finds the comic image on each page
- Downloads the image
- Saves the downloaded images in a local folder

## Technologies

- Python
- Requests
- BeautifulSoup
- OS

## How to run

Install the required libraries:
