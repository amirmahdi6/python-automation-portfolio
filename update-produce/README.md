# Update Produce

A Python script that updates product prices in an Excel spreadsheet.

## Chapter

Chapter 13 - Working with Excel Spreadsheets

## What This Project Does

The script reads product information from an Excel workbook, updates the prices according to the defined rules, and saves the modified data to a new Excel file.

## Files

* `E1_updateproducte.py` - Main Python script
* `produceSales.xlsx` - Original Excel workbook
* `updatedProduceSales.xlsx` - Updated Excel workbook

## Technologies

* Python
* `openpyxl`
* Excel spreadsheet manipulation
* File handling

## How to Run

Install the required package:

```bash
pip install openpyxl
```

Then run:

```bash
python E1_updateproducte.py
```

The script processes `produceSales.xlsx` and creates the updated workbook.
