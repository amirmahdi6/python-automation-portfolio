# Date Organizer

A Python automation script that organizes files by changing their date format in filenames.

## Chapter
Chapter 10 - Organizing Files

## What This Project Does

This script searches for files with dates in their filenames and changes the date format to make the filenames more organized and consistent.

## Files

- `e1_change.py` - Main Python script
- `hello 4-7-2025.txt` - Example input file
- `report 25-12-2024.txt` - Example input file

## Technologies

- Python
- Regular Expressions
- File Handling
- `os`
- `shutil`
